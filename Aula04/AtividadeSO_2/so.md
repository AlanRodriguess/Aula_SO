# Sistemas Operacionais Baseados em Outros Sistemas

## 1. Sistemas Operacionais pesquisados

### Ubuntu

O Ubuntu é um sistema operacional baseado no Debian. Ele utiliza a arquitetura e muitos pacotes, ferramentas e técnicas provenientes do Debian, mas possui desenvolvimento, ciclo de versões, foco e configurações próprias.

O Ubuntu foi criado para oferecer uma distribuição com foco em facilidade de uso, segurança, suporte e utilização em desktops, servidores e ambientes de nuvem.

### Android

O Android é uma plataforma de software baseada no kernel Linux. O kernel Linux é a base responsável por funções de baixo nível, como gerenciamento de memória, processos, segurança e comunicação com o hardware.

O Android adiciona várias camadas próprias, como o Android Runtime (ART), bibliotecas, framework de APIs e componentes específicos para dispositivos móveis.

### SteamOS

O SteamOS é uma distribuição Linux baseada no Arch Linux. A Valve utiliza a base do Arch Linux e adiciona componentes próprios voltados principalmente para jogos e para dispositivos como o Steam Deck.

Entre as principais modificações estão a interface voltada para jogos, o Steam Client, configurações específicas de hardware, drivers e componentes destinados à execução de jogos.

### elementary OS

O elementary OS é construído utilizando tecnologias do Ubuntu e do Debian. Ele utiliza componentes e repositórios do Ubuntu como parte importante de sua base, mas possui seus próprios componentes de interface e aplicativos.

Um dos principais diferenciais é o ambiente de desktop Pantheon, desenvolvido pelo próprio projeto, além de aplicativos próprios e uma experiência de usuário diferente da distribuição Ubuntu tradicional.

### Linux Mint

O Linux Mint é uma distribuição baseada em tecnologias do Ubuntu e do Debian. Ele utiliza os repositórios do Ubuntu e mantém compatibilidade com grande parte dos recursos, programas e ferramentas disponíveis para Ubuntu.

O projeto adiciona componentes próprios e ambientes gráficos como Cinnamon, MATE e Xfce, buscando oferecer uma experiência de desktop mais tradicional e simples.

## 3. Comparação entre os sistemas e suas bases

### Ubuntu × Debian

O Ubuntu utiliza o Debian como uma de suas principais bases. Os dois sistemas possuem muitas tecnologias em comum, mas o Ubuntu possui um processo de desenvolvimento próprio.

O Ubuntu possui um ciclo de lançamento definido, seleciona e mantém seus próprios conjuntos de pacotes e possui foco em diferentes ambientes, como desktop, servidores e nuvem.

Portanto, o Ubuntu não é simplesmente uma cópia do Debian. Ele utiliza o trabalho desenvolvido no Debian e acrescenta modificações e decisões próprias.

### Android × Linux

A relação entre Android e Linux é principalmente baseada no kernel.

O Android utiliza o kernel Linux como fundamento para gerenciamento de recursos de baixo nível. Entretanto, o Android possui uma arquitetura própria voltada para dispositivos móveis.

Enquanto uma distribuição Linux tradicional normalmente utiliza componentes como GNU, ambientes de desktop e ferramentas tradicionais de uma distribuição, o Android utiliza componentes específicos para celulares, tablets, televisores, carros e outros dispositivos.

### SteamOS × Arch Linux

O SteamOS utiliza o Arch Linux como base.

A principal diferença está no objetivo do sistema. O Arch Linux é uma distribuição de propósito geral, enquanto o SteamOS foi desenvolvido para oferecer uma experiência otimizada para jogos.

A Valve acrescenta componentes próprios, integração com o Steam, configurações específicas de hardware e recursos voltados para dispositivos como o Steam Deck.

### elementary OS × Ubuntu

O elementary OS utiliza o Ubuntu como uma importante base de software e repositórios.

Apesar disso, possui uma identidade própria. O projeto desenvolve o ambiente de desktop Pantheon, aplicativos próprios e diversas configurações específicas.

Dessa forma, o usuário encontra uma experiência de utilização diferente daquela encontrada em uma instalação padrão do Ubuntu.

### Linux Mint × Ubuntu

O Linux Mint utiliza os repositórios do Ubuntu e mantém compatibilidade com grande parte dos programas e recursos desenvolvidos para Ubuntu.

Porém, o Linux Mint possui ferramentas e ambientes gráficos próprios. O Cinnamon, por exemplo, fornece uma experiência de desktop diferente da configuração padrão de outras distribuições.

---

## 4. Conclusão

Os cinco sistemas analisados mostram que um Sistema Operacional pode aproveitar diferentes partes de outro projeto sem ser necessariamente igual ao sistema utilizado como base.

O Ubuntu utiliza o Debian como base para pacotes, ferramentas e infraestrutura. O Android utiliza o kernel Linux como fundamento de sua arquitetura. O SteamOS utiliza o Arch Linux como base e adiciona recursos voltados para jogos. O elementary OS utiliza tecnologias e repositórios do Ubuntu e Debian, mas desenvolve sua própria experiência de desktop. O Linux Mint utiliza principalmente os repositórios do Ubuntu e componentes provenientes do ecossistema Debian.

Esses exemplos demonstram que o desenvolvimento de um Sistema Operacional pode ocorrer por meio do aproveitamento de código, kernel, pacotes, bibliotecas, ferramentas e estruturas já existentes. A partir dessa base, cada projeto pode acrescentar novos componentes e adaptar o sistema para objetivos específicos.
